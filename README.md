# Vintage Loom

---

A fork of [Architectury Loom](https://github.com/architectury/architectury-loom) that is a fork of [Fabric Loom](https://github.com/FabricMC/fabric-loom) that supports the Forge modding toolchain.  
Strongly based off of [architectury-loom#138](https://github.com/architectury/architectury-loom/pull/138).  

A [Gradle](https://gradle.org/) plugin to setup a deobfuscated development environment for Minecraft mods.  

* Built in support for tiny mappings and MCP mappings  
* Utilises the Vineflower decompiler (and others) to generate source code with comments  
* Designed to support legacy and modern versions of Minecraft (1.7.10 and upwards)  
* Built in support for IntelliJ IDEA, Eclipse and Visual Studio Code to generate run configurations for Minecraft  
* Loom targets the latest version of Gradle 8 or newer  
* Supports Java 21 upwards  

## Usage

View the [Architectury Loom documentation](https://docs.architectury.dev/loom/introduction) for usages.
